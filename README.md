## 📋 О проекте

# Реализация алгоритмов машинного обучения с нуля

Данный репозиторий содержит собственную реализацию ключевых алгоритмов машинного обучения на Python. Основной упор сделан на понимание внутреннего устройства моделей, а также на оптимизацию вычислений с использованием многопроцессорной обработки (`joblib`).

## Структура и возможности

### `my_GBDT.py`
**Градиентный бустинг на решающих деревьях (Gradient Boosting Decision Trees)**
*   Реализация классификатора на основе градиентного бустинга.
*   Использует композицию "слабых" учеников (решающих деревьев) для минимизации ошибки.
*   Поддержка настройки основных гиперпараметров: количество деревьев (`n_estimators`), скорость обучения (`learning_rate`), максимальная глубина деревьев (`max_depth`).

### `my_dtree_fast_optim.py`
**Решающие деревья и ансамбли с мультипроцессингом**
*   **Decision Tree:** Базовая реализация решающего дерева.
*   **Random Forest:** Реализация случайного леса, строящего множество деревьев на случайных подвыборках данных и признаков.
*   **Extra Random Forest (Extremely Randomized Trees):** Реализация ультра-рандомного леса с еще более сильной рандомизацией при выборе порогов разделения.
*   🚀 **Оптимизация:** Для ускорения обучения ансамблей используется многопроцессорный режим из библиотеки `joblib`, что позволяет эффективно задействовать все ядра процессора.

### `my_regression.py`
**Линейные модели и масштабирование данных**
*   **Линейная регрессия:**
    *   Обычная (Ordinary Least Squares).
    *   Ридж-регрессия (L2-регуляризация).
    *   Лассо (L1-регуляризация).
    *   Elastic Net (комбинация L1 и L2 регуляризации).
*   **Методы обучения:** Все модели линейной регрессии обучаются с помощью градиентного спуска (в том числе мини-батчами).
*   **Препроцессинг:** Реализованы собственные классы `MinMaxScaler` и `StandardScaler` для нормализации и стандартизации признаков.

### `my_classification.py`
**Методы классификации**
*   **Логистическая регрессия (Logistic Regression):** Бинарный классификатор на основе сигмоидальной функции.
*   **Метод k-ближайших соседей (KNN):** Непараметрический алгоритм классификации.
*   **Смешанный наивный байесовский классификатор (Mixed Naive Bayes):** Версия наивного Байеса, способная работать как с категориальными, так и с непрерывными признаками.
*   **Метрики качества:** Реализован подсчет метрики **ROC-AUC** для оценки качества бинарной классификации.

### `my_validation.py`
**Инструменты валидации и отбора признаков**
*   **Кросс-валидация (K-Fold):**
    *   Обычный K-Fold.
    *   Стратифицированный K-Fold (Stratified K-Fold) для сохранения пропорций классов.
    *   Групповой K-Fold (Group K-Fold) для независимых групп данных.
    *   Кросс-валидация для временных рядов (Time Series K-Fold).
*   **Подбор гиперпараметров:**
    *   **GridSearchCV:** Полный перебор по сетке значений параметров.
    *   **RandomizedSearchCV:** Случайный поиск по заданному распределению параметров.
*   **Важность признаков:** Реализован механизм оценки важности признаков на основе перестановок (**Permutation Importance**).
