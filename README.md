# 🚀 Реализация алгоритмов машинного обучения с нуля

Данный репозиторий содержит собственную реализацию ключевых алгоритмов машинного обучения на Python. Основной упор сделан на понимание внутреннего устройства моделей, а также на оптимизацию вычислений с использованием многопроцессорной обработки (`joblib`). Каждый алгоритм реализован "с нуля" с использованием только базовых библиотек.

## 📓 Jupyter Notebooks: мини-исследования

*   🔬 **Сравнение реализаций:** Сопоставление самописных алгоритмов с эталонными из `scikit-learn`

*   📈 **Исследование гиперпараметров:** Влияние параметров на качество моделей и скорость обучения
*   🔍 **Примеры использования:** Пошаговые демонстрации работы каждого алгоритма на реальных и синтетических датасетах

## 📦 Структура и возможности

### 🌳 `my_GBDT.py`
**Градиентный бустинг на решающих деревьях (Gradient Boosting Decision Trees)**

*   🎯 Реализация классификатора на основе градиентного бустинга
*   🔨 Использует композицию "слабых" учеников (решающих деревьев) для минимизации ошибки
*   ⚙️ **Гиперпараметры:**
    *   `n_estimators` - количество деревьев в ансамбле
    *   `learning_rate` - скорость обучения (шаг градиентного спуска)
    *   `max_depth` - максимальная глубина деревьев
    *   🌟 **`max_features` - метод случайных подпространств** 
        *   Позволяет каждому дереву обучаться на случайном подмножестве признаков
        *   Уменьшает корреляцию между деревьями и борется с переобучением
        *   Поддержка как фиксированного числа признаков, так и процента от общего количества

### ⚡ `my_dtree_fast_optim.py`
**Решающие деревья и ансамбли с мультипроцессингом**

*   🌲 **Decision Tree:** Базовая реализация решающего дерева с поддержкой критериев Джини и энтропии
*   🌲🌲 **Random Forest:** Случайный лес на случайных подвыборках данных и признаков
*   ⚡ **Extra Random Forest (Extremely Randomized Trees):** 
    *   Ультра-рандомный лес с еще более сильной рандомизацией
    *   Случайный выбор порогов разделения вместо поиска оптимальных
*   🚀 **Оптимизация:** Многопроцессорный режим из библиотеки `joblib` для эффективного использования всех ядер процессора

### 📈 `my_regression.py`
**Линейные модели и масштабирование данных**

*   **Линейные модели:**
    *   📊 Обычная линейная регрессия (Ordinary Least Squares)
    *   👑 Ридж-регрессия (L2-регуляризация)
    *   🎯 Лассо (L1-регуляризация)
    *   🔗 Elastic Net (комбинация L1 и L2 регуляризации)
*   **Методы обучения:** 
    *   📉 Полный градиентный спуск
    *   📊 Стохастический градиентный спуск (по батчам)
*   **Препроцессинг:**
    *   📏 `MinMaxScaler` - масштабирование в заданный диапазон
    *   📐 `StandardScaler` - стандартизация (Z-score нормализация)

### 🏷️ `my_classification.py`
**Методы классификации**

*   📈 **Логистическая регрессия (Logistic Regression):** Бинарный классификатор на основе сигмоидальной функции
*   👥 **KNN (k-ближайших соседей):** Непараметрический алгоритм с поддержкой различных метрик расстояния
*   🎲 **Mixed Naive Bayes:** 
    *   Смешанный наивный байесовский классификатор
    *   Работает как с категориальными, так и с непрерывными признаками
    *   Гауссово распределение для непрерывных признаков
*   📊 **Метрики качества:** Реализация **ROC-AUC** для оценки качества бинарной классификации

### 🔬 `my_validation.py`
**Инструменты валидации и отбора признаков**

*   **Кросс-валидация (K-Fold):**
    *   🔄 Обычный K-Fold
    *   📊 Стратифицированный K-Fold (Stratified K-Fold) для сохранения пропорций классов
    *   👥 Групповой K-Fold (Group K-Fold) для независимых групп данных
    *   ⏰ Кросс-валидация для временных рядов (Time Series K-Fold)
*   **Подбор гиперпараметров:**
    *   🎯 **GridSearchCV:** Полный перебор по сетке значений параметров
    *   🎲 **RandomizedSearchCV:** Случайный поиск по заданному распределению параметров
*   **Важность признаков:** 
    *   💡 **Permutation Importance** - оценка важности на основе перестановок
    *   Устойчив к мультиколлинеарности
    *   Работает с любой моделью
